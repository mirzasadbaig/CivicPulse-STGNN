Explore more of the real data

The uploaded community file contains 21 recorded snapshots. The full build includes observed counts and saved original forecast scores where available; optional imports can add local exports. Community colors are available only on the 21 saved dates.

No synthetic daily values are created. Additional visible changes must come from measured data.

Reading this research visualization. Nodes represent (ZIP code, complaint category). Within-ZIP edges are confirmed from model construction; geographic edges are shown only after reconstructing the graph from the original NYC CSV. Community colors show Louvain partitions on the 21 saved dates. A changing complaint count or model probability does not necessarily mean the community must change. The model forecasts elevated 48-hour complaint counts, not verified emergencies. These scores are from the original single-seed 2025 run, not the revised 2026 evaluation. In the revised benchmark, persistence outperforms geographic GCN–GRU in both F1 and AP; see the repository manuscript.
